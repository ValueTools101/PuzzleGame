How to Play

Goal

Every island shows a target number. Swipe to slide every tile at once. Tiles that collide combine into one — land a tile exactly on the target before your moves run out.

Operators

Pick + − × ÷ before you swipe. Colliding number tiles combine using whichever operator is selected, in the order they meet — so the same swipe gives a different result depending what you've chosen.

Special Tiles

MirrorFlips the sign of whatever number drifts into it, no matter which operator is selected.
WildcardCopies the number that merges with it and doubles it.
FreezeA frozen island. It never moves and never merges — everything else has to work around it.

Moves

Each swipe costs one move, even if nothing merges. A swipe that changes nothing on the board is free. Fewer moves used earns more stars.
